Multiplayer caveat
- This environment did not perform a live two-device network smoke test or a physical-phone performance test. To use two devices locally, keep the server running and access it via the server computer's LAN IPv4 address. For players on different networks, deploy the HTTP and WebSocket server to a public host or configure a secure public endpoint.
