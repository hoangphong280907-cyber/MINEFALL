Feature: configurable match duration

Implemented:
- Offline configuration offers exactly 10, 15, 20, 25 and 30 minutes.
- Online room creation offers the same five options and stores the selected value in the authoritative room config.
- Online server deadline, countdown, room label, pregame summary, HUD badge, progress bar, timeout title and rematch timer honor the selected duration.
- Default duration remains 10 minutes for existing clients/configurations that omit the new field.
- Server rejects unsupported durations, including values below 10 minutes or above 30 minutes.
